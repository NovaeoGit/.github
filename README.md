# .github

This is the Novaeo organization meta-repository. It powers the [org profile README](profile/README.md) and hosts organization-wide discussions.

## What's Here

- **`profile/README.md`** — The public-facing organization profile displayed at [github.com/NovaeoGit](https://github.com/NovaeoGit)
- **Discussions** — Org-wide Q&A, knowledge sharing, and training follow-ups (enable in repo Settings > Discussions)

## For the Team

Visit the [organization page](https://github.com/NovaeoGit) to see the full repo catalog and reference links.

Use [Discussions](https://github.com/NovaeoGit/.github/discussions) to:
- Ask questions about skills, agents, or any repo
- Share patterns and techniques you've discovered
- Post training follow-up questions
- Propose new skills or improvements
